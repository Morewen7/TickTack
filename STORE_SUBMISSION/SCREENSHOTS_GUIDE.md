# Гайд по снятию скриншотов для магазинов

## Требования по размерам

| Магазин | Минимум | Максимум | Размер (px) |
|---|---|---|---|
| **GetApps** | 2 | 10 | 1080×1920 |
| **Galaxy Store** | 2 | 10 | 1080×1920 |
| **APKPure** | 1 | 5+ | любой (оптимизирует сам) |

## Как снять скриншот на Android

**Способ 1: Стандартный (easiest)**
- Зажми одновременно: **Кнопка питания + Громкость вниз**
- Скриншот сохраняется в Галерею → Screenshots

**Способ 2: Через меню**
- Нажми: **Кнопка питания** → "Скриншот"
- (Работает на Android 9+)

**Способ 3: Жест (если включен)**
- Свайп сверху вниз на панели уведомлений → "Скриншот"

## Рекомендуемый набор скриншотов

### Скриншот 1: Главный экран
**Что показать:**
- Как минимум 3 списка в табах (Все, Личное, Работа)
- 5-10 задач в списке
- FAB кнопка внизу (+ для новой задачи)
- Видна системная панель

**Подготовка:**
1. Откройте приложение
2. Убедитесь, что есть несколько задач в "Личное" списке
3. Снимите скриншот

### Скриншот 2: Добавление новой задачи
**Что показать:**
- Модальное окно добавления напоминания
- Поля: Название, Заметка, Дата, Время, Приоритет
- Все функции видны

**Подготовка:**
1. На главном экране нажмите FAB кнопку (+)
2. Заполните пример:
   - Название: "Купить молоко"
   - Заметка: "В магазин недалеко от дома"
   - Приоритет: Medium
3. Снимите скриншот (не сохраняя)
4. Закройте (← Назад)

### Скриншот 3: Детали задачи
**Что показать:**
- Открытую задачу с подзадачами
- Выполненные и невыполненные подзадачи
- Заметка и метаданные

**Подготовка:**
1. На главном экране нажмите на одну из задач
2. Откроется детальный экран
3. Снимите скриншот

### Скриншот 4: Геолокация / Место
**Что показать:**
- Экран выбора места
- Город и страна (например, "Москва, Россия")
- Выбранный радиус срабатывания

**Подготовка:**
1. На детальном экране задачи нажмите "Добавить место"
2. Нажмите "+ Использовать текущее место"
3. Дождитесь определения локации (покажет город, страну)
4. Выберите радиус (например, 500м)
5. Снимите скриншот

### Скриншот 5: Настройки / Приватные списки
**Что показать:**
- Экран настроек
- Список с иконкой замка (приватный список)
- Опция Face ID / Touch ID
- Переключение тёмной темы

**Подготовка:**
1. На главном экране нажмите значок ☰ (меню)
2. Нажмите "Настройки"
3. Прокрутите до "Списки"
4. Снимите скриншот

### Скриншот 6: Темная тема (опционально)
**Что показать:**
- Тот же главный экран, но в тёмной теме
- Красиво выглядит!

**Подготовка:**
1. Настройки → "Тёмная тема" (включить)
2. Вернитесь на главный экран
3. Снимите скриншот

## Постобработка скриншотов (опционально)

**Если нужно добавить текст/стрелки:**

Для Linux/Mac:
```bash
# Например, с помощью ImageMagick:
convert screenshot1.png -pointsize 24 -fill white -annotate +50+50 "Главный экран" screenshot1_labeled.png
```

Для Windows:
- Paint
- Photoshop
- Онлайн инструменты (Canva, Pixlr)

**Оптимизация размера:**
```bash
# Уменьшить размер файла
convert screenshot1.png -quality 90 screenshot1_optimized.jpg
```

## Загрузка скриншотов в магазины

### GetApps & Galaxy Store
1. При загрузке приложения будет форма "Upload Screenshots"
2. Нужно загрузить в правильном порядке
3. Формат: PNG или JPG (1080×1920 px)
4. Максимум 10 шт

### APKPure
1. На форме загрузки найти "Screenshots"
2. Загрузить файлы (автоматически оптимизирует)
3. Максимум 5 шт (но можно больше)

## Быстрый способ получить скриншоты прямо на Mac

```bash
# Пулл первого скриншота с устройства
adb pull /sdcard/DCIM/Screenshots/screencap*.png ~/Desktop/

# Или сразу все скриншоты
adb pull /sdcard/DCIM/Screenshots/ ~/Desktop/screenshots/
```

## Советы по красивым скриншотам

✓ Убедитесь, что статус-бар читаемый (не скрыт)
✓ Используйте реальные данные (названия задач, реальные города)
✓ Показывайте темную тему (выглядит красивее)
✓ Не включайте клавиатуру на скриншотах
✓ Убедитесь, что видны все ключевые функции

## Проверка перед загрузкой

- [ ] 5-8 скриншотов (не меньше 2, не больше 10)
- [ ] Размер 1080×1920 px (или автоматически оптимизируется)
- [ ] Формат PNG или JPG
- [ ] Все функции приложения видны
- [ ] Текст читаемый
- [ ] Нет приватной информации
- [ ] Скриншоты в правильном порядке (от простого к сложному)
