# GetApps (Xiaomi) - Метаданные

## Название приложения
TickTack

## Краткое описание (80 символов)
Умные напоминания с геолокацией и приватными списками

## Полное описание
TickTack — приложение для управления задачами и напоминаниями с интеллектуальными функциями.

**Основные возможности:**
✓ Напоминания по времени и местоположению (GPS)
✓ Подзадачи и подробные заметки  
✓ Приватные списки с защитой отпечатком пальца / Face ID
✓ Синхронизация через облако
✓ Сортировка по дате, приоритету или алфавиту
✓ Статистика выполнения задач
✓ Темная тема

**Идеально для:**
• Планирования дел
• Списков покупок
• Профессиональных проектов
• Персональных задач

Бесплатно

## Скриншоты (размер: 1080×1920 px)
Нужно 5-8 скриншотов:
1. Главный экран со списками
2. Добавление новой задачи
3. Детали задачи с подзадачами
4. Выбор места (геолокация)
5. Настройки / приватные списки
6. Темная тема (опционально)

## Требования к аккаунту
1. Зарегистрироваться на https://developer.xiaomi.com
2. Пройти верификацию (может быть долго)
3. Загрузить приложение в AppStore Developer Console

## Статус проверки
Обычно 1-3 рабочих дня
