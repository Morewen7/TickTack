## 📸 Скриншоты: 5 минут работы

Используй встроенный инструмент скриншотов:
**Power Button + Volume Down** одновременно

Нужно снять:
1. Главный экран (список задач)
2. Добавление новой задачи
3. Детали задачи (с подзадачами)
4. Выбор геолокации (город, радиус)
5. Настройки (приватные списки, блокировка)

Подробно: см. `SCREENSHOTS_GUIDE.md`
