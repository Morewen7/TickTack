# Galaxy Store (Samsung) - Метаданные

## Название приложения
TickTack

## Краткое описание
Умные напоминания с геолокацией и приватными списками

## Полное описание
TickTack — приложение для управления задачами и напоминаниями с интеллектуальными функциями.

**Основные возможности:**
✓ Напоминания по времени и местоположению (GPS)
✓ Подзадачи и подробные заметки
✓ Приватные списки с защитой отпечатком пальца / Face ID
✓ Синхронизация через облако
✓ Сортировка по дате, приоритету или алфавиту
✓ Статистика выполнения задач
✓ Темная тема
✓ Оптимизировано для Samsung устройств

**Идеально для:**
• Планирования дел
• Списков покупок
• Профессиональных проектов
• Управления приватной информацией
