# APKPure - Метаданные

## Название приложения
TickTack

## Краткое описание
Умные напоминания с геолокацией и приватными списками

## Полное описание
TickTack — приложение для управления задачами и напоминаниями с интеллектуальными функциями.

**Основные возможности:**
✓ Напоминания по времени и местоположению (GPS)
✓ Подзадачи и подробные заметки
✓ Приватные списки с защитой отпечатком пальца / Face ID
✓ Синхронизация через облако
✓ Сортировка по дате, приоритету или алфавиту
✓ Статистика выполнения задач
✓ Темная тема

## Ключевые слова
напоминания, задачи, геолокация, список дел, приватные списки

Productivity

Размер: 512×512 px (PNG)

3-5 скриншотов:

4. Геолокация
5. Настройки

## Версия
1.0.0

## Минимальная версия Android
Android 8.0 (API 26)

## Требования к аккаунту
1. Перейти на https://apkpure.com
2. Нажать "UPLOAD YOUR APPS" или "Developer"
3. Создать аккаунт разработчика
4. Загрузить APK файл

## Что нужно подготовить
1. Release APK: `/Users/mmm/Documents/TickTack/android/app/build/outputs/apk/release/app-release.apk`
2. Иконка приложения (512×512 PNG)
3. Скриншоты
4. Описание приложения

## Статус проверки
Обычно 1-3 часов (очень быстро)
